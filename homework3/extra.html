WURFL Database

Describe 3 capabilities offered by WURFL database.

The is_robot capability is a boolean check to identify "non-human" traffic, such as search engine crawlers, spiders, and social media scrapers. It allows developers to optimize server performance and clean up their data. For example, a developer can use this capability to ensure that website analytics accurately reflect real human engagement rather than being skewed by web crawlers.
The device_os capability identifies the specific operating system running on a requesting device, such as iOS, Android, Windows, or macOS. This capability allows developers to make high-level functional decisions. For example, a developer can use this capability to automatically display the correct download button for a mobile app (Apple App Store vs. Google Play) or a desktop application (.exe for Windows vs. .dmg for Mac). This ensures the user is directed to the software compatible with their specific hardware.
The is_full_desktop capability is a boolean check used to confirm if a user is accessing an application from a computer rather than a tablet or mobile device. It allows developers to serve feature-rich versions that are optimized for large screens and mouse-based input. For example, if the boolean returns a false, then this request is from a tablet or mobile device, so the developer might choose to collapse the sidebar by default to allow maximum real estate for actual contents.
